FEATURES

今ある機能

現在のまる Addons に搭載されている主な機能です。

FPS

Browser FPS

ブラウザ側の描画フレームレートをパネルに表示します。

60

60FPS Mode

Alt + スタートボタンでScratchランタイムを60FPS動作へ切り替え。もう一度で通常動作へ戻せます。

#

ブロック数表示

現在のプロジェクト内に存在するブロック数を表示します。

ON

Scratch FPS

Scratchランタイム側のステップ間隔からFPSを確認できます。

VM

VM取得

ScratchのVMを検出し、ランタイムやターゲットへのアクセスを行います。

↗

共有解除

プロジェクトページの「共有されたもの」を「非共有」として扱い、共有解除操作を実行します。

INSTALL

学タブでも、1回貼るだけ。

拡張機能をインストールできない環境では、Scratchを開いてDevToolsのConsoleに下のコードを貼り付けて実行します。

1
Scratchを開くプロジェクトページなど、Scratchのページを開きます。
2
DevTools → Consoleブラウザの開発者ツールでConsoleを開きます。
3
コードを貼ってEnter下のボタンでコピーして、そのまま実行します。
注意: まる Addons はScratch非公式のツールです。Scratch側の仕様変更などで動作しなくなる場合があります。
Console / loader
fetch("https://raw.githubusercontent.com/maru-m4ru-maru/maru-addons/main/content.js")
  .then(r => r.text())
  .then(eval);

現在はコンソール実行を中心に提供しています。Scratch本体のアップデートによってDOMやランタイム内部が変わると、一部機能が動かなくなる可能性があります。

問題を見つけたらGitHubのIssueやプロジェクトページなどで報告してください。
