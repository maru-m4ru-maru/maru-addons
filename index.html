WHAT IT DOES

入れるだけで、Scratchがちょっと強くなる。

現在のまる Addons に搭載されている主な機能をまとめています。

FPS

FPSモニター

ブラウザ側のFPSと、ScratchランタイムのFPSを画面上で確認できます。

60

60FPSモード

再生ボタンを Alt+クリックして、Scratchランタイムを60FPSで動かすモードを切り替えられます。

#

ブロック数表示

プロジェクト内のブロック総数を取得して表示します。

VM

Scratch VMアクセス

ScratchのステージからVMを取得し、ランタイムやターゲットへアクセスできる開発向け基盤を備えています。

↩

共有解除

「共有されたもの」を非共有操作へ置き換え、プロジェクトの共有解除を実行できます。

⚡

軽量・一発起動

常駐拡張機能が使えなくても、コンソールから読み込むだけですぐ試せます。

QUICK START

使い方は、ほぼ1動作。

学タブなどで拡張機能を入れられない場合でも使える、コンソール版の起動方法です。

コンソールから起動
1
Scratchのプロジェクトを開くScratchのプロジェクト画面でDevToolsを開きます。
2
Consoleを開くChrome系ブラウザなら F12 → Console などで開けます。
3
下のコードを貼り付けて実行GitHub上の最新版 content.js を読み込んで、そのまま起動します。

※ Scratchや学校環境のポリシーに従って利用してください。

Console 
fetch("https://raw.githubusercontent.com/maru-m4ru-maru/maru-addons/main/content.js")
  .then(r => r.text())
  .then(eval);

main ブランチの content.js を直接読み込むため、更新後も同じコマンドで最新版を起動できます。
